Getting started

Your first recovery.

From zero to a broken Nginx server in a few commands.

1. Install the prerequisites

Install Docker Desktop, OrbStack, or Docker Engine. Then install MLM:

curl -fsSL https://dhanh-ryuu.github.io/install.sh | sh

2. Check your machine

mlm version
mlm doctor

doctor verifies that the Docker CLI and daemon are available.

3. Load the issue catalog

mlm catalog update https://github.com/dhanh-ryuu/machine-lives-matter-distribution/releases/download/scenarios-v0.2.0/catalog.json
mlm list

4. Enter the incident

mlm info nginx-502
mlm start nginx-502

The first start downloads a verified scenario bundle and builds its image locally. Later starts use the cached bundle.

5. Check your repair

exit
mlm check nginx-502
MLM checks observable machine state, not the exact commands you ran. Different valid solutions can pass.
