The Uninvited
Worker.

An application health marker keeps returning to a degraded state. Something left behind by maintenance is still running.

Start solving Back to issues

Incident report

Operators repair /srv/app/health.state, but the change never lasts. Use process names and command-line arguments to find the cause.

Your objective: stop the responsible process and restore a stable healthy state.

Constraints

  • Identify the process from the running machine.
  • Do not repeatedly overwrite the marker as a workaround.
  • The repaired state must remain stable.

Start the issue

mlm start rogue-worker

When the state remains healthy:

exit
mlm check rogue-worker
