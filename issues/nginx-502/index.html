Nginx returns
502 Bad Gateway.

The website is down. Nginx is alive, but it cannot complete requests. Restore the endpoint without replacing the machine.

Start solving Back to issues

Incident report

Users report that the local Nginx endpoint returns 502 Bad Gateway. The proxy itself is running, so the failure is somewhere along the request path.

Your objective: restore the service so an HTTP request to http://127.0.0.1/ succeeds.

What you have

  • Root access inside a disposable Linux container.
  • Standard process, network, filesystem, and Nginx diagnostic tools.
  • A state-based checker. Your command history is not inspected.

Constraints

  • Do not replace or remove Nginx.
  • The final endpoint must return a successful HTTP response.
  • You may solve the issue using any valid diagnostic path.

Start the issue

Install the MLM CLI and make sure Docker is running. Then launch the scenario:

mlm doctor
mlm catalog update https://github.com/dhanh-ryuu/machine-lives-matter-distribution/releases/download/scenarios-v0.2.0/catalog.json
mlm start nginx-502

When you believe the service is repaired, leave the shell and run:

exit
mlm check nginx-502
