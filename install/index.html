Install once.
Break things safely.

MLM is a single binary for macOS and Linux. Docker is the only runtime dependency.

Recommended

Install script

Detects your operating system and CPU, verifies the release checksum, and installs mlm.

curl -fsSL https://dhanh-ryuu.github.io/install.sh | sh

Requirements

Docker Engine

Docker Desktop, OrbStack, or Docker Engine must be installed and running.

Docker install guide

Verify the installation

mlm version
mlm doctor

Install manually

Download the archive for your platform from the public distribution release, verify it against checksums.txt, and place the binary somewhere on your PATH.

Download release

Uninstall

rm /usr/local/bin/mlm

If installed to a user-local directory, remove ~/.local/bin/mlm instead.
